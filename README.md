I'm a second-year Computer Science student at the **Faculty of Computer and Data Science (FCDS), Alexandria University**, driven by curiosity about how intelligent systems learn and how data pipelines turn raw information into decisions. My work spans **machine learning, data science, and full-stack development**, and I'm currently extending that foundation into **data engineering**.

- 🎓 CS Student, FCDS · Alexandria University — expected graduation 2027
- 🔧 Currently completing the **DEPI (Digital Egypt Pioneers Initiative) — Microsoft Data Engineer track** (6 months)
- 🤖 Building agent-based AI systems, automation bots, and classic full-stack projects
- 🌍 Based in Alexandria, Egypt

## Featured Projects

> Pulled straight from [github.com/mo7-s3d690](https://github.com/mo7-s3d690) — these are the projects I'm actively building.

### 🤖 [Talenta-automation-project](https://github.com/mo7-s3d690/Talenta-automation-project)
Four agent architectures — **reactive rules, unconstrained ReAct, deterministic routing, and constrained ReAct** — solving the same CV-screening decision (accept / reject / idle) for a simulated recruiting company. Built to compare how different agent designs trade off reliability, flexibility, and cost.
`Python`

### 🏨 [Hotel-Management-System](https://github.com/mo7-s3d690/Hotel-Management-System)
A fully functional hotel management system with an interactive interface and a complete backing database — covering bookings, rooms, and guest records end-to-end.
`PHP`

### 🐦 [x_bot2.0](https://github.com/mo7-s3d690/x_bot2.0)
A Python automation bot for X (Twitter), handling scripted interactions on the platform.
`Python`
